# NovaCRM Demo

Çok şubeli işletmeler için hazırlanmış, mock veri kullanan CRM ve yönetim paneli demosu.

## Demo kapsamı

- Genel bakış dashboard'u
- Müşteri ve lead takibi
- İşlem ve sipariş takibi
- Şube yönetimi
- Personel yönetimi
- Ürün ve hizmet kataloğu
- Gelir, gider ve kasa görünümü
- Raporlar
- Rol ve yetkilendirme
- Sistem ayarları
- Responsive mobil menü ve tablolar

Bu sürüm yalnızca arayüz sunumudur. Gerçek veritabanı, kimlik doğrulama, CRUD ve yetki kontrolleri iş kapsamı netleştikten sonra bağlanacaktır.

## Çalıştırma

```bash
npm install
npm run dev
```

Ana adres doğrudan `/panel` sayfasına yönlenir. `/login` altında mock giriş ekranı bulunur.
